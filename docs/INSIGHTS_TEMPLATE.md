# Insight Writing Template
Use actual dashboard filters and values before completing this page. Do not leave placeholders in a submitted final report.

1. **Global trend:** During [date window], the 7-day average of reported cases [rose/fell] from [value] to [value] ([country/global aggregate]).
2. **Country comparison:** For [same date window], [Country A] reported [value] and [Country B] reported [value] on the selected measure.
3. **Deaths trend:** The 7-day average of reported deaths [description] in [country/date window].
4. **Data quality:** [N] negative cumulative-difference revisions were flagged for [country/date window]. Chart values floor these at zero; the raw derived column remains available.
5. **Interpretation caveat:** The supplied files do not contain population and vaccination coverage fields, so no per-million or vaccination-effect claim is supported.

Always include the date window, metric, and country/region. Distinguish observed association from causation.
